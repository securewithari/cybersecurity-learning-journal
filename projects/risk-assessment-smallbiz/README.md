## 📌 Project Overview

This project is a beginner risk assessment performed on a fictional small 
technology company called **SmallBiz Tech**. It demonstrates my ability to:

- Identify assets and their value to an organization
- Identify threats and vulnerabilities
- Calculate risk scores using likelihood and impact
- Recommend security controls to reduce risk
- Document findings in a professional format

## 🎯 Key Takeaways

- Every organization has risks — the goal is to manage them, not eliminate them
- Risk = Likelihood × Impact
- Controls should be matched to the risks they address
- Documentation and evidence are everything in GRC work
